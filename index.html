Built for learning

Explore the core functions of this simple embedded measurement system.

📏

Height calculation

Calculates height by subtracting the sensor-to-head distance from the fixed sensor mounting height.

🖥️

LCD readout

Displays the measured height on a 16×2 I²C LCD with one decimal place for centimeters.

🔘

One-button unit switch

Cycle through centimeters, meters, and feet using a push button connected to digital pin D2.

Upload the firmware

Use the Arduino IDE for this Arduino UNO version.

Download the sketch

Click “Download Arduino Code” to save Ultrasonic_Height_Meter.ino.

Install the LCD library

In Arduino IDE, open Library Manager and install a compatible LiquidCrystal_I2C library.

Connect your board

Connect the Arduino UNO by USB, then choose Tools → Board → Arduino UNO and select the correct port.

Verify and upload

Open the downloaded sketch, click Verify, then Upload. Open Serial Monitor at 9600 baud to see readings.

Why no one-click browser flash button?
This project targets the classic Arduino UNO. ESP Web Tools is designed for ESP-family firmware, so its installer cannot directly flash this UNO sketch. Use Arduino IDE for now; a browser-based UNO flasher needs a compatible AVR flashing implementation and compiled firmware image.
