Ultrasonic
Height Meter

A practical Arduino UNO project that measures a person's height using an HC-SR04 ultrasonic sensor and displays the result on an I²C LCD. Watch the tutorial, explore the components, and download the Arduino source code to build your own.

Built for learning

Explore the core functions of this simple embedded measurement system.

📏

Height Calculation

Calculates height by subtracting the sensor-to-head distance from the fixed sensor mounting height.

🖥️

LCD Readout

Displays the measured height on a 16×2 I²C LCD with one decimal place for centimeters.

🔘

One-Button Unit Switch

Cycle through centimeters, meters, and feet using a push button connected to digital pin D2.

Upload the Firmware

Use the Arduino IDE for this Arduino UNO version.

Download the Sketch

Click the download button to save Ultrasonic_Height_Meter.ino.

Install the LCD Library

Open Library Manager in Arduino IDE and install a compatible LiquidCrystal_I2C library.

Connect Your Board

Connect the Arduino UNO by USB. Choose Tools → Board → Arduino UNO and select the correct port.

Verify and Upload

Open the downloaded sketch, click Verify, then Upload. Open Serial Monitor at 9600 baud to see readings.

About browser-based flashing
This project targets the classic Arduino UNO. ESP Web Tools is designed for ESP-family firmware and cannot directly flash this UNO sketch. Use Arduino IDE for now; browser-based UNO flashing requires a compatible AVR flashing implementation and compiled firmware image.
