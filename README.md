# smart-height-measuring-device
Build your own Ultrasonic Height Meter using Arduino UNO! 📏🔧

In this DIY electronics project, I built a simple and low-cost digital height measurement system using an HC-SR04 ultrasonic sensor, Arduino UNO, LCD display and a push button.

The ultrasonic sensor is fixed at approximately 7 feet from the ground and measures the distance between the sensor and the top of the person's head. Arduino then calculates the actual height and displays it on the LCD.

The system can display height in centimeters, meters and feet. The current measurement can also be monitored through the Arduino Serial Monitor.

📐 How It Works
The HC-SR04 ultrasonic sensor sends an ultrasonic pulse toward the person's head and measures the time taken for the echo to return.

Arduino calculates the distance using the speed of sound and then calculates:

Person's Height = Sensor Height − Measured Distance

The result is converted into cm, meters and feet and displayed on the LCD.
